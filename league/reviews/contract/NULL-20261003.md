0.33% (stock) and 0.67% (incumbent, 11 values). The classic SD (2.3-4.4%) is those two runs.

## What changed because of it

- **Probe bands** (`noise_aware_probes`, on from S017). `launch.py` `NULL_20261003` sets the config keys
  `probe_pair_sd_time_pct` / `probe_pair_sd_score_pct` 0.5, `probe_pair_sd_rss_pct` 2.5 and the per-phase table
  (time 0.9 / 0.6 / 1.0 / 0.8 / 0.8 / 1.35 / 0.3; RSS 5.9 / 6.2 / 6.9 / 5.5 / 6.0 / 5.4 / 1.6): the larger of the
  official and research-lane readings, rounded up. A one-round probe now resolves a whole-workload time move of
  ±1.0% (was ±2.2%). The code defaults in `tools/league_targets.py` (1.11 / 2.22, the 2026-09-24 values) are
  unchanged, so `tests/test_noise_aware_probes.py` is unchanged and passes; `probe_null_source` (new config key)
  names this file in the noise block. A single phase reading that is off by seconds is a stall: rerun it.
- **Gates: unchanged** (29/42 wins, median ≥ 0.25%, 5% axis cap, +2% memory guard). On this null the 29/42 rule has
  a false-positive rate of ~0 and full power at a true +0.5%. Tightening or loosening a gate is the operator's call.
- **Not measured:** the null of the `big-index` and `large-files` workloads (probes on them use main's per-phase
  values), and research lanes under a full season's load.
